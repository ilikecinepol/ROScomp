## Как использовать находки для симулятора

1. Сейчас: внешний вид стоек, оснований, рамп, пола и помех взять из обзорных листов; размеры пока параметризовать по заданию и явно помечать как ориентировочные.
2. Реальные обработанные сетки использовать как отдельные тестовые входы планировщика. Их конфликтующие клетки и кандидаты не превращать автоматически в объекты мира.
3. После получения оригиналов: выделить синхронизированные фазы ручного прохода; оценить отклик на команды, задержки, видимость, окклюзии и шум. Проверить фактическую геометрию датчиков перед метрической реконструкцией.
4. Реконструировать размеры/взаимное расположение с оценкой ошибки; не считать дрейфующую одометрию точной геодезией и не объединять разные эпохи координат без привязки.
5. Сохранить отдельные раскладки для проверки переносимости: точное повторение старого ручного маршрута не является автономным решением меняющейся арены.

Есть расхождение источников: прежние планы разработки описывают четыре физических препятствия, загруженное задание — пять с отдельным мостом. Обзорные листы не дают основания исключать мост из полной миссии; для окончательной модели требуется сверить состав фактической полосы.
