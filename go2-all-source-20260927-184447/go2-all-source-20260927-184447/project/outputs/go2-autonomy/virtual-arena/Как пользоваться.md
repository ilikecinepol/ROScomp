# Карта и виртуальный прогон Go2

Откройте двойным щелчком «Карта и виртуальный прогон.html». Установка и интернет не нужны.

1. Выберите реальную запись: карта сверху и соответствующий кадр камеры. Ползунок переключает начало, середину и конец записи. Красные точки поверх корпуса — конфликт занятости с его габаритом.
2. Выберите «Учебная сцена · не полигон», нажмите «Виртуальный прогон». Путь рассчитан тем же plan_slalom, что используется в бортовом пакете.
3. Для проверки остановки включите «Щелчок по карте — другая собака» и щёлкните на пути. Модель остановится при пересечении запаса. Уберите объекты и повторно нажмите запуск для продолжения.
4. «Пауза» останавливает показ. «Сначала» возвращает начальную позицию и убирает добавленные объекты.

Ограничения: учебные стойки расставлены через 1,8 м на искусственном свободном полу. Это не копия полигона. Модель не воспроизводит физику лап, устойчивость, сетевые задержки или динамику приводов. Поворот показан по направлению сегмента пути, без ограничений углового ускорения. Добавленные собаки неподвижны; обход не реализован. Реальные карты построены с неподтверждённой привязкой одометрии и лидара, поэтому их маршруты не разрешают движение. Команды на Pi отсутствуют.

Источники: четыре локально скачанные записи 26.09.2026, три снимка каждой. Время сцен указано по Москве. Привязка камеры по времени получения не гарантирует совпадение времени съёмки.

Проверено: построение 12 реальных снимков и одной учебной сцены, конечность координат отрисовки, завершение учебного пути, остановка/продолжение при препятствии, пауза и запрет прогона реальных записей. Проверка JavaScript выполнена в Node с имитацией элементов страницы. Визуальная проверка браузером не выполнена: инструмент запретил file://.
