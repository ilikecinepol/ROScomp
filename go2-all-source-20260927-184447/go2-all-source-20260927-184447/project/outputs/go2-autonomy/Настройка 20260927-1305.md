# Настройка 27 сентября, продолжение

Установлен пакет `training-34b67f45779a87528f2c`. Прежняя версия сохранена. 294 теста полной серии прошли. Это не подтверждение автономного физического прохождения; боевого профиля по-прежнему нет.

## Исправления

- `wolf_go2/recovery.py`: до начала движения отсутствующий поток переподписывается автоматически; видео переключается off/on. Максимум две попытки на поток, интервал шесть секунд. Появление пакетов подтверждает только доставку, не время измерения. Одинаковый source stamp при свежих пакетах не вызывает бесконечный перезапуск. Во время начавшейся миссии модуль не восстанавливает разрешение движения.
- `poles.exclude_body_conflicts`: кандидат, пересекающий ориентированный корпус с учётом неопределённости позы, исключается из ряда змейки. Кандидат и точки карты остаются, причина пересечения не объявляется собственным отражением.

На записи `20260927T095407.476020Z` прежний четвёртый кандидат [-4.15,1.7] попадал внутрь корпуса при позе [-4.060149,1.769758,-0.074285]. После исправления остаются три кандидата; максимальное отклонение от линии около 2 см. Камера также выделяет три силуэта. Совпадение количества не является их калиброванным сопоставлением и не доказывает полноту змейки.

## Проверенные гипотезы

Сохранён исходный пакет в сеансе Pi `20260927T095706.667960Z`: raw-lidar.bin/json. Сравнение native и установленного libvoxel: 29428 занятых вокселей, 44422 уникальные вершины сетки; каждая вершина соседствует с занятым вокселем native. Ошибка перестановки осей в декодере этой проверкой не обнаружена. Системы координат и время измерения проверка не подтверждает.

Прочитаны INSTRUCTION.md и ROS2.md организаторов на Pi. Их ROS-мост не публикует лидар/камеру; установка этого моста не решает проблему датчиков. Для справки скачаны, но не запускались исходники https://github.com/abizovnuralem/go2_ros2_sdk, commit b440609591a249e7bdd4bbc88e056a3660575447. Репозиторий публикует одометрию с прибавкой z=0.07 и включает пример калибровки камеры. Эти параметры не перенесены в проверенный профиль нашего экземпляра.

В последних сеансах содержимое лидара меняется, timestamp постоянен внутри сеанса, но между сеансами изменился с 1790502000 на 1790503000. Это согласуется с грубым округлением, но точность и задержка измерения ещё не установлены. Не заменять время съёмки временем получения без явного измеренного контракта.
