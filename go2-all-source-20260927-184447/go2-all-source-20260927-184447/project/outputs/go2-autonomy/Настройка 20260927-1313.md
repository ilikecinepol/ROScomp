## Изменения

- Новые пары облако/камера сохраняют полный кватернион и заголовок ROBOTODOM. Анализ больше не обязан предполагать нулевые крен и тангаж.
- Новый `wolf_go2/association.py` сопоставляет объекты один-к-одному с возможностью оставить объект без пары. Далёкие пары отбрасываются. Неоднозначность оценивается повторным оптимальным назначением с запретом проверяемой пары, а не только сравнением двух ближайших объектов.
- Этот модуль пока используется офлайн-инструментом `audit_camera_projection.py`; установка его на Pi сама по себе не включает распознавание в исполнительном контуре.
- `replay_camera_series.py` проверяет всю доступную серию и исключает дубликаты по идентификатору загрузки Pi, эпохе и времени получения. Полная ориентация старых кадров автоматически извлекается из точной строки samples.jsonl, когда журнал имеется; иначе явно указан вариант с нулевыми roll/pitch.

## Результат на записях

93 уникальные пары, один дубликат исключён. Ошибок обработки нет. В 38 кадрах камера выделила не менее трёх стоек. В 10 кадрах сопоставлены три пары с заданными пределами расстояния и неоднозначности. Остальные не считать успешно калиброванными. Это не доказательство прохождения и не достаточная универсальная калибровка.

Детали: diagnostic-20260927/camera-series.json. Параметры камеры всё ещё из стороннего SDK, а не измеренная калибровка этого экземпляра. Полнота змейки не установлена. Привязка времени лидара и поддержка пола под корпусом остаются нерешёнными. В основном восприятии кандидаты слалома всё ещё не получают strong_geometry=true автоматически: одного существования кнопки или подходящего числа силуэтов недостаточно.
