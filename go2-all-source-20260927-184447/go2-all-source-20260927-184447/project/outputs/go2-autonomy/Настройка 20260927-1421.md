## Изменения основной программы

1. `wire_audit.py`: аудит точного значения метки до разбора SDK, только в observe. Пакеты и штатный SDK не изменяются, движение не разрешается.
2. `preparation.py`: отдельная диагностическая причина `coarse_constant_number_on_wire`, вместо попытки выдать оценку приёма за калибровку исходных часов.
3. `mission.py`: при входе в допустимый угол ALIGN выдаёт нулевую команду и ждёт устойчивого направления минимум 0,4 с. Оцениваемая по последовательным позам скорость поворота должна быть не выше 0,08 рад/с; линейная скорость — не выше 0,05 м/с. Повтор/перестановка наблюдения, разрыв данных, потеря опоры или выход из допуска сбрасывают выдержку.
4. `models.py`: добавлены параметры alignment_settle_seconds и alignment_max_yaw_rate. Пределы скорости движения не увеличены.

Выравнивание и раньше использовало ошибку измеренного yaw; новое изменение исправляет преждевременное завершение по одному наблюдению. Это не новый полностью готовый регулятор движения и не проверка физической точности одометрии. Изменение применяется к переходу ALIGN → TRAVERSE и завершению отдельного подхода, не ко всем поворотам на маршруте.
