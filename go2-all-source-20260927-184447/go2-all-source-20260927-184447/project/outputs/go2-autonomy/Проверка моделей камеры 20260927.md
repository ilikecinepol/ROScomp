# Проверка моделей камеры

В этой итерации проверялись гипотезы на сохранённых данных. Робот не подключался, движение не запускалось, установленная версия и профиль не менялись.

## Проверенные варианты

1. 81 комбинация горизонтального масштаба 0,8–1,2 и смещения −40…+40 пикселей на 54 кадрах с тремя или более визуальными кандидатами. Пороги сопоставления не изменялись.
2. 27 комбинаций положения камеры относительно корпуса: x=0,15/0,33/0,50 м, y=−0,08/0/+0,08 м, yaw=−5/0/+5 градусов, z=0,04 м. Проверены четыре кадра из разных сеансов. Это поисковые параметры, не измерения реальной конструкции.

В первой сетке не нашлось модели, получающей минимум три соответствия хотя бы в одном кадре каждого рассматриваемого сеанса. Во второй сетке не нашлось модели с тремя соответствиями одновременно на всех четырёх кадрах. Это не доказывает отсутствие подходящей физической калибровки: сетки ограничены, соответствия объектов сами ещё не подтверждены.

Наиболее равномерный результат второй сетки — 3/2/2/2 соответствия. Исходная модель даёт 2/3/3/1. Замена исходной модели не обоснована; ни одна поправка не установлена.

## Изменения инструментов

- `scan_projection_models.py` воспроизводит проверку масштаба и смещения и сохраняет все результаты, включая неоднозначные максимумы.
- `audit_camera_projection.audit` принимает явную гипотезу смещения и поворота камеры; использованные параметры сохраняются в отчёт с verified=false.
- Проверено совпадение результата модели по умолчанию с предыдущим разбором; некорректные параметры отклоняются.
- Данные: `diagnostic-20260927/projection-model-scan.json` и `extrinsic-model-scan.json`.

Поиск использовал проверяемые записи для сравнения вариантов. Поэтому результаты нельзя выдавать за независимую проверку найденной калибровки.

## Что проверять дальше

Следует проверять соответствие физических объектов, неполноту облака и систему координат, а не автоматически выбирать модель с наибольшим количеством совпадений. Пока не установлено, какой вклад дают параметры камеры, неверный кандидат стойки и геометрия облака. Задача автономного прохождения остаётся незавершённой.
