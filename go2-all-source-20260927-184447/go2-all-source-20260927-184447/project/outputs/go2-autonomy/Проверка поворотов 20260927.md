Нельзя считать скорость команды фактической угловой скоростью робота или переносить эти значения на другие режимы.

## Анализ и изменения

- `audit_rotation_timing.py` сопоставляет движение изображения с одометрией. Для первого опыта лучшая относительная оценка — 0,10 с, ошибка около 2,27 пикселя. Это не измерение абсолютной задержки камеры и не подтверждённая калибровка.
- Добавлены явные результаты `insufficient_rotation` и `insufficient_observations`: отсутствие пригодных данных больше не выглядит как успешный расчёт с пустым списком.
- Проверяется строгое возрастание времени одометрии. Синтетические проверки покрывают известный сдвиг времени, слабый поворот, повторяющиеся метки и отсутствие визуальных соответствий.
- Полный локальный набор: 324 теста прошли. Это проверка программной логики, не доказательство физического прохождения полосы.
- На Pi ранее в этой работе установлен пакет `training-20f302d9ddf7692acf78`, сохраняющий параметры видеокадров. Диагностические изменения анализатора выполняются на ПК; проверенный профиль автономии не создан.

Данные: `diagnostic-20260927/20260927T105222Z` и `diagnostic-20260927/20260927T105929Z`. В каждом каталоге есть `summary.json`, `samples.jsonl`, фотографии, `motion-evidence.json` и `rotation-timing-analysis.json`. В последнем явно указано `calibration_verified: false`.

## Что осталось для работающей автономии

1. Получить воспроизводимый отклик поворота с контролем измеренного угла, ограничением времени и подтверждённой остановкой. Не повышать скорость автоматически по единственному слабому опыту.
2. Подтвердить геометрию камера–лидар на нескольких положениях. Найденные параметры чужого Go2 и подбор по одному кадру пока не подходят: устойчивого соответствия трёх стоек нет.
3. Решить проверку свежести исходных данных: у лидара постоянная исходная метка, временная шкала видео расходится со временем получения. Частые сообщения сами по себе не подтверждают свежесть измерения.
4. Подключить подтверждённые соответствия к бортовому распознаванию ряда и проверить свободный маршрут. Сейчас `cylinder_slalom.py` ещё не подтверждает полноту ряда автоматически.
5. Испытать змейку, затем отдельные остальные препятствия и только после этого всю петлю. Успешные ручные записи не доказывают готовность автономного контроллера.

Не создавать фиктивный `autonomy-profile.json` и не выставлять признаки проверки без измерений. Следующий запуск движения должен опираться на текущее положение робота и доступность площадки, а не на старое изображение.
