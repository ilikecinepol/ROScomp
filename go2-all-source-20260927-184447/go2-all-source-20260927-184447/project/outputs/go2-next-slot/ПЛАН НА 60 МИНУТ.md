# Go2 — подготовка и план часового тренировочного слота

Составлено 16.09.2026 по фактически полученным данным. Доступ к роботу сейчас отключён; этот документ не запускает подключение или движение.

## Результат, ради которого используем следующий час

Получить проверенную запись работы датчиков и короткого движения с остановкой. Установить, какие координаты и метки времени пригодны для следующего этапа — самостоятельного подхода к препятствию. Полное прохождение полосы в этом слоте не обещаем: отдельные навыки ещё не подтверждены физическими испытаниями.

Минимальный полезный результат: полная запись неподвижного робота с проверкой актуальности камеры, сведения о доступных потоках, версиях и системах координат. Если движение не допускают состояние робота или качество данных, слот всё равно должен дать материал для работы вне полигона.

## Что уже есть и чего ещё нет

- Получены камера, готовая воксельная карта, состояние и одометрия.
- Есть обнаружение рампы на ограниченном наборе близких ракурсов. Распознавание всех препятствий не подтверждено.
- Есть программа короткого движения и анализатор записи. Семь проверок ограничителя на поддельном транспорте проходят; физический тест движения ещё не состоялся.
- Последняя подготовка завершилась без Move; штатная служба была восстановлена и проверена.
- Не подтверждены калибровка камеры, согласование времени и пригодность сообщаемого курса для навигации. Заранее известные координаты раскладки в алгоритм не закладываем.

## Подготовка до слота

### 1. Упаковать испытание

- [ ] Один запуск с ПК: проверка подключения, загрузка проверенной версии, показ состояния, получение результата.
- [ ] Один управляющий процесс на Pi для последовательных этапов записи и теста; один владелец соединения с роботом.
- [ ] Общее ограничение длительности сессии, локальная на Pi остановка, обработка прерывания и восстановление штатной службы.
- [ ] Автоматическая доставка свежего кадра и состояния на ПК. Одноразовое разрешение движения после их просмотра и подтверждения готовности полигона; движение по умолчанию выключено.
- [ ] Контрольные суммы исходников и настройки записываются рядом с результатом.
- [ ] Подготовлены основной проверенный вариант и предыдущий проверенный вариант для отката. Экспериментальная версия имеет отдельное имя.

Это план доработки: единого готового запуска пока нет. Имеющиеся отдельные скрипты не выдавать за завершённый пакет.

### 2. Проверить отказные ситуации без робота

- [ ] Пропала камера, остановились или пошли назад метки времени, пришли повторные пакеты.
- [ ] Не пришёл ответ на движение или остановку, произошла ошибка записи журнала, процесс прервали.
- [ ] Разрешение движения истекло, относится к другой сессии или уже использовано.
- [ ] Подготовленное испытание не продолжает движение после отказа проверки.
- [ ] Разобрана семантика поля Sport `error_code`: оно может обозначать режим. Не считать любой штатный переход аппаратной неисправностью и не объявлять неизвестный код безопасным.

### 3. Подготовить пригодную запись

- [ ] Для каждого потока сохраняются исходная метка и время получения на Pi; для видео — PTS и time_base.
- [ ] Проверяется наличие всех потоков, необходимых конкретному опыту, а не только двух потоков состояния.
- [ ] Есть нумерация кадров/пакетов, счётчики пропусков и ошибок. Крупные данные пишутся через ограниченную очередь; переполнение видно в отчёте.
- [ ] После опыта формируется один архив и краткая сводка. Скачивание проверяется по размеру/контрольной сумме и открытию файлов.
- [ ] Анализ записей проверен на существующих материалах: ему не требуется подключение к роботу.

### 4. Согласовать организацию

- [ ] Уточнить, можно ли заранее загрузить пакет и зависимости на Pi. Если доступа нет, приготовить их локально под фактические версии Python и архитектуру.
- [ ] Получить ответы о калибровке, времени видео/лидара, назначении систем координат и допустимых переходах режима.
- [ ] Назначить одного человека, который руководит испытанием, и согласовать связь с оператором физического полигона.
- [ ] Заранее выбрать два-три опыта и записать для каждого вопрос, команду, условие остановки и ожидаемые данные.

## Расписание следующего слота

| Минуты | Действие | Проверяемый результат |
|---|---|---|
| 00–05 | Подключение, проверка назначенного Pi, версии пакета и свежих данных | Подтверждён нужный робот и доступность потоков; движения нет |
| 05–12 | Неподвижная запись; оператор в тренировочном режиме показывает и убирает предмет перед камерой | Камера актуальна; сохранены курс, гироскоп, карта и времена |
| 12–22 | При выполненных условиях — первый короткий импульс вперёд и остановка | Записаны команда, ответ, наблюдаемое движение и состояние после остановки |
| 22–35 | Повтор заранее выбранного опыта; при необходимости дополнительные неподвижные ракурсы | Проверена повторяемость либо собраны данные о конкретном отказе |
| 35–45 | Сбор видов входа рампы и её краёв с разных доступных положений | Материал для распознавания и геометрии; автономный заезд на рампу не предполагается |
| 45–52 | Один контрольный повтор самого полезного опыта | Есть сопоставимая контрольная запись |
| 52–60 | Завершение испытаний, проверка остановки и восстановления штатной службы, выгрузка и проверка архива | Данные доступны команде вне слота, состояние завершения записано |

Если отдельный навык подхода будет реализован и проверен до начала слота, его испытание можно заранее включить вместо части сбора ракурсов. Импровизированный заезд на препятствие не подменяет подготовленный опыт.

## Как не потерять час на одну проблему

- Если за первые 10 минут доступ не восстановлен, передать оператору/организатору краткий факт сбоя и его время; не менять сетевую инфраструктуру вслепую.
- На один непонятный отказ отвести до 5 минут первичной диагностики. Сохранить журнал; повторять опыт после конкретного исправления, а не в надежде на другой результат.
- При невыполненных условиях движения переключиться на неподвижную запись и сбор ракурсов с помощью оператора, если это разрешено форматом тренировки.
- Каждая попытка меняет один параметр. Перед изменением известна проверяемая гипотеза.
- После 52-й минуты новые двигательные опыты не начинать; оставить время на завершение и данные.

## Распределение команды

| Роль | Ответственность |
|---|---|
| Руководитель испытания | Общение с оператором, выбор следующего подготовленного опыта, подтверждение готовности |
| Инженер запуска | Один управляющий сеанс, версия программы, состояние соединения и завершение |
| Аналитик | Проверка полноты записи, быстрый разбор результатов, журнал гипотез и выводов |

Один человек может совмещать роли. Одновременно команды роботу отправляет только один управляющий процесс. Вычисления и разбор на ПК относятся к подготовке и тренировочным данным; зачётное решение должно выполнять всю работу на разрешённом бортовом компьютере.

## Работа между слотами

Разбирать все сохранённые данные, улучшать распознавание на новых ракурсах, проверять код на записи и моделируемых отказах. Собственная Go2 Air может помочь с общей организацией записи и распознаванием макета входа, но поведение походки и интерфейсы нужно отдельно подтвердить на предоставленном Go2 Pro.

К следующему слоту готовить уже изменённую и проверенную версию и небольшой список конкретных опытов. На полигоне получать сведения, которые невозможно достоверно получить по старой записи.
