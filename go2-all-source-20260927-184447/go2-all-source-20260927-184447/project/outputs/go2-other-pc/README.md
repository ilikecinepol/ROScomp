# Go2: подключение с другого Windows-ПК

Комплект настроен для pi-0008, адрес 192.168.11.81. Актуально для текущего назначения команды на 17.09.2026. Если организаторы сменят назначение, используйте новые адрес и ключ. Серверная программа уже установлена на нашем Pi; на новом ПК нужен только клиент. Свой Raspberry Pi покупать не требуется.

## 1. Что подготовить

- Этот архив: распаковать полностью, например в C:\Go2. Не запускать прямо из ZIP.
- Windows OpenSSH Client: в PowerShell команда `ssh -V` должна показывать версию. Если команды нет, установить компонент «Клиент OpenSSH» через дополнительные компоненты Windows.
- Python 3.12 с компонентом Tcl/Tk и Python Launcher. Проверка: `py -3.12 --version`. Если Python отсутствует, установить с официального сайта Python, включив Tcl/Tk и Launcher.
- OpenVPN Connect и выданный команде профиль robot_8.ovpn.
- Выданный команде SSH-ключ pi-0008.txt. Профиль VPN и ключ передать отдельно по защищённому каналу уполномоченному участнику; их нет в этом архиве. Не выкладывать их в Git или общий чат.

Перед переходом на другой ПК завершить управление на первом: «Завершить и сохранить», дождаться закрытия. Не подключать два управляющих клиента одновременно. Для одного VPN-профиля завершить старое VPN-подключение перед подключением нового ПК.

## 2. VPN

Открыть OpenVPN Connect → Import Profile → File → выбрать robot_8.ovpn → подключиться. Дождаться Connected. Профиль должен быть именно для текущего выданного доступа.

## 3. Разместить SSH-ключ

Сохранить pi-0008.txt в Загрузки нового пользователя. Открыть PowerShell от обычного пользователя и выполнить:

```powershell
$keyDir = Join-Path $env:USERPROFILE '.ssh\go2-pi-0008'
New-Item -ItemType Directory -Force -Path $keyDir | Out-Null
$keyFile = Join-Path $keyDir 'id_ed25519'
Copy-Item -LiteralPath "$env:USERPROFILE\Downloads\pi-0008.txt" -Destination $keyFile
$account = [System.Security.Principal.WindowsIdentity]::GetCurrent().Name
icacls $keyFile /inheritance:r
icacls $keyFile /grant:r "${account}:(R)"
```

Если Загрузки перенесены в другую папку, изменить только путь исходного pi-0008.txt. Не печатать содержимое ключа. Использовать ту же учётную запись Windows для SSH и запуска окна.

## 4. Проверить SSH один раз

```powershell
ssh -o IdentitiesOnly=yes -i "$env:USERPROFILE\.ssh\go2-pi-0008\id_ed25519" ubuntu@192.168.11.81
```

При первом входе SSH покажет отпечаток ключа сервера: сверить с организаторами или с доверенным ранее подключённым ПК; после совпадения принять. При предупреждении об изменившемся ключе не удалять старую запись вслепую — проверить смену устройства.

После входа выполнить `hostname`: ожидается pi-0008. Затем `exit` — вернуться в PowerShell своего ПК. Адрес .81 используется для SSH, а не для открытия страницы HTTPS. Обычный вход по SSH сам не запускает окно с камерой.

## 5. Подготовить клиент один раз

В PowerShell перейти в распакованную папку, например:

```powershell
cd C:\Go2
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install Pillow
```

Интернет нужен здесь для установки Pillow. OpenCV и ROS на ПК для этого окна не нужны. Для проверки окна без робота:

```powershell
.\.venv\Scripts\python.exe .\work\go2-teleop\keyboard_client.py --dry-run
```

Это демонстрация, не камера полигона. Закрыть её перед настоящим подключением.

## 6. Открыть управление

Дважды щёлкнуть **START.cmd** на новом ПК. Либо в его PowerShell:

```powershell
.\.venv\Scripts\python.exe .\work\go2-teleop\keyboard_client.py --host 192.168.11.81
```

Эту команду НЕ вводить внутри SSH на Pi. Окно появляется на вашем ПК. Клиент сам по SSH запускает запись на Pi и временно освобождает WebRTC-подключение от штатной fleet-dog. После завершения восстанавливает эту службу, если она была включена. Подготовка может занять несколько десятков секунд.

Перед разрешением движения убедиться, что идёт тренировочный слот, робот стоит на полу, путь свободен и оператор полигона готов остановить его. Нажать «Разрешить управление», дождаться готовности. Разрешённые режимы — normal и mcf (допуск mcf подтверждён пользователем).

| Клавиши | Действие |
|---|---|
| Пробел + W / S | Вперёд / назад, до 0,6 м/с |
| Пробел + A / D | Поворот влево / вправо, до 1 рад/с |
| Пробел + Q / E | Вбок влево / вправо, до 0,5 м/с |
| Отпустить Пробел | Остановить движение |
| X, Escape, СТОП | Остановить и снять разрешение |

При диагонали суммарная поступательная команда ограничена 0,6 м/с. При смене окна, потере свежей связи/камеры или ошибке записи допуск снимается. Нужно разрешить управление снова. Предпросмотр камеры около 2 кадров/с; запись JPEG до 5 кадров/с. Это не плавное видео 30 FPS. Сеанс ограничен пятью минутами.

## 7. Сохранить и скачать

Запись начинается автоматически, даже до разрешения движения. Нажать «Завершить и сохранить» и дождаться окончания. В PowerShell своего ПК из папки комплекта выполнить:

```powershell
New-Item -ItemType Directory -Force .\recordings | Out-Null
scp -r -o IdentitiesOnly=yes -i "$env:USERPROFILE\.ssh\go2-pi-0008\id_ed25519" ubuntu@192.168.11.81:/home/ubuntu/ai-robot/team_wolf_setup/teleop_logs .\recordings
```

Папка recordings\teleop_logs содержит отдельные сеансы: камера/JPEG, воксельные карты, телеметрия, команды/ответы, summary.json и run_status.json. Скачать перед окончанием доступа к Pi. Это материал для будущего алгоритма; координаты дрейфуют, карта обработанная, временная синхронизация не подтверждена. Запись не является готовым автономным маршрутом.

## Если не запускается

- Таймаут SSH: проверить VPN, слот и актуальный адрес.
- Permission denied (publickey): проверить назначенный ключ, имя ubuntu и права файла.
- Host key verification failed: выполнить первый ручной вход и сверить отпечаток. Клиент автоматически незнакомому серверу не доверяет.
- No such file run_teleop.py: на назначенном Pi нет нашей серверной программы; этот комплект рассчитан на уже настроенный pi-0008.
- No module named PIL: установить Pillow именно через .venv\Scripts\python.exe.
- Ошибка Tcl/Tk: восстановить компонент Tcl/Tk установки Python; не использовать Python из внутренней папки Codex на новом ПК.
- Нет камеры/робот занят: закрыть другой управляющий клиент, не запускать вторую программу параллельно. Журналы клиента: outputs\go2-teleop\client-logs.
- Запрещённый режим или нет подтверждения остановки: сохранить сообщение и передать оператору; не отключать проверку.

Работа с клавиатуры предназначена для тренировочного слота. На зачётном автономном прогоне ручное вмешательство запрещено.
