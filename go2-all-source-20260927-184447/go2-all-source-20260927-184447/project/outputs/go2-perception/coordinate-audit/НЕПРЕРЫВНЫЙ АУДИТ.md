## PTS видео

- Первый PTS 180, последний 22860; разница **22680**.
- У всех 14 сохранённых кадров `time_base = 1/90000`.
- При применении объявленного time_base длительность между этими кадрами — **0.252000 с**.
- Между их приёмами проходит **26.404474 с**; отношение приём/PTS — **104.779658**.
- Скорость PTS по приёму — **857.813668 тиков/с**, вместо 90000 тиков на секунду при масштабе 1:1.
- Разности соседних сохранённых PTS: [1800, 1740, 1740, 1740, 1740, 1740, 1740, 1740, 1740, 1740, 1740, 1740, 1740]; их НОД — 60. Это описывает сохранённые кадры, а не доказывает шаг каждого из 396 декодированных кадров.

В этой записи PTS с указанным time_base **не соответствует масштабу времени приёма**. По данным нельзя выбрать правильный альтернативный time_base или объявить конкретную причину: это может требовать проверки назначения PTS, RTP/декодирования и промежуточных преобразований. Автоматически умножать PTS на найденное отношение для «исправления синхронизации» нельзя.
