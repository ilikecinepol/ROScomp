## Соединение с роботом

Штатная служба `fleet-dog` занимает единственное WebRTC-соединение. Документ организатора `ROS2.md` разрешает временно останавливать и запускать её через `sudo systemctl stop/start fleet-dog`. **Между отдельными подключениями**, после отключения предыдущего клиента, выдерживать примерно **15 секунд**. После успешного `go2.connect` дополнительная пауза перед подпиской на датчики не требуется: штатные примеры `01` и `02` подписываются сразу.

Документированные стандартные значения скорости CLI: **0,6 / 0,5 / 1,0**. Это справочная информация, не результаты испытаний и не разрешение запускать движение.

Локальные файлы находятся в `C:\Users\VladO\Documents\Codex\2026-09-09\new-chat\work\go2-remote-access`, удалённые — в `/home/ubuntu/ai-robot/team_wolf_setup`:

## Команды для следующего агента

В `C:\Users\VladO\Documents\Codex\2026-09-09\new-chat\outputs\go2-remote-setup` созданы `connect.ps1` и `Подключиться к Raspberry Pi.cmd`. Последний открывает SSH-сеанс, не отправляя команд движения роботу.

PowerShell на локальном ПК; VPN должен быть подключён. Использовать сохранённый ключ узла, не отключать его проверку:

```powershell
$go2Ssh = @(
    '-i', 'C:\Users\VladO\.ssh\go2-pi-0008\id_ed25519',
    '-o', 'IdentitiesOnly=yes',
    '-o', 'BatchMode=yes',
    '-o', 'StrictHostKeyChecking=yes',
    '-o', 'UserKnownHostsFile=C:\Users\VladO\Documents\Codex\2026-09-09\new-chat\work\go2-remote-access\known_hosts',
    '-o', 'ConnectTimeout=10',
    'ubuntu@192.168.11.82'
)
& ssh @go2Ssh 'hostname'
& ssh @go2Ssh 'systemctl is-active fleet-dog'
& ssh @go2Ssh 'tail -n 100 /home/ubuntu/ai-robot/team_wolf_setup/last_run.log'
& ssh @go2Ssh 'ls -lt /home/ubuntu/ai-robot/team_wolf_setup/logs'
```

Повторную диагностику запускать последовательно, после завершения предыдущего прогона и проверки состояния службы:

```powershell
& ssh @go2Ssh '/home/ubuntu/ai-robot/venv/bin/python -u /home/ubuntu/ai-robot/team_wolf_setup/run_sensor_probe.py'
& ssh @go2Ssh 'systemctl is-active fleet-dog'
```

Если ранее активная служба не восстановилась, после завершения диагностики:

```powershell
& ssh @go2Ssh 'sudo -n systemctl start fleet-dog'
& ssh @go2Ssh 'systemctl is-active fleet-dog'
```

Не запускать параллельные WebRTC-клиенты, не заменять штатные файлы проекта и не считать старые результаты симуляции L1 доказательством работы на физическом роботе.
