# Go2: новая версия ручного управления v2

Основная инструкция: [HTML-памятка](../go2-training-v2/Go2%20—%20подключение,%20запись%20и%20план%20автономности.html).

Переносимый комплект: `outputs/Go2-training-v2.zip`. В нём клиент для Windows и два серверных файла для Pi. Старый архив «Go2-другой-ПК.zip» — предыдущая версия.

На этом ПК прежний ярлык «Запустить управление Go2.cmd» запускает обновлённый клиент. До следующего подключения загрузите оба файла из `go2-training-v2/server/` на Pi по разделу 5 памятки. Удалённая версия в рамках этой работы не обновлялась.

Просто удерживайте W/S, A/D, Q/E. Пробел и кнопка разрешения не нужны. Подготовка автоматическая, но подключение само движения не вызывает. После потери фокуса/связи отпустите клавиши и нажмите заново. X/Esc — стоп.

По умолчанию профиль «Точный»: 0,10 м/с вперёд. Выбор скорости — в списке. Значения для препятствий ещё требуют физических испытаний.

Камера доступна до начала записи. Нажмите «Начало записи», дождитесь «ПИШЕМ», выполните попытку, затем «Конец записи» и дождитесь подтверждения сохранения. Каждая попытка — отдельный run_001/run_002 на Pi внутри каталога сеанса. Диагностический журнал ведётся весь сеанс. «Завершить и сохранить» закрывает подключение; лимит сеанса 300 секунд.

Проверки и расположение исходников: [СОСТОЯНИЕ-v2.md](СОСТОЯНИЕ-v2.md).
