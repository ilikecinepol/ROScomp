# Go2: ручное управление v2

Откройте HTML-памятку в этой папке. Распакуйте весь комплект в C:\Go2.

Новая версия ещё не установлена на Pi. Загрузите оба server/*.py по инструкции перед запуском START.cmd. Ключи и VPN-профиль передаются отдельно.

Движение при удержании W/S/A/D/Q/E без Пробела, подготовка автоматическая. Стоп: отпускание направлений, X, Esc, потеря фокуса/связи. Запись датчиков — только между кнопками начала и конца; диагностический журнал ведётся весь сеанс. Лимит сеанса 300 секунд.

Профили (вперёд, вбок, поворот): точный 0.10/0.08/0.20; препятствие 0.15/0.10/0.25; пол 0.30/0.15/0.50; быстрый 0.60/0.50/1.00. Первые два числа м/с, третье рад/с. Это исходные настройки для испытаний, а не подтверждённые безопасные скорости прохождения.
