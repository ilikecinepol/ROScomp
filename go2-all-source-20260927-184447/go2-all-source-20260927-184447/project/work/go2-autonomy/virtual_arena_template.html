Источник и причины блокировки




Прогон доступен только в учебной сцене. Он использует путь бортового планировщика, но показывает лишь движение по плоскости: без физики лап, сцепления и задержек команд. Добавленная собака моделируется кругом радиуса 0,35 м; при пересечении запаса модель останавливается. Автоматический объезд здесь не реализован.


В каждой реальной записи показаны три снимка: начало, середина и конец. Пунктир — заблокированный участок кандидата маршрута, а не команда движения. Позиция робота на реальной карте взята из сохранённой одометрии.
